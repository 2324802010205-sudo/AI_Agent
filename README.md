# AI_Agent

AgentScope — AI Agent Desktop & Backend workspace with multi-Skill runtime, SkillGuard OFF/ON sanitization & security evaluation, and MCP workbook analysis tools.

## Structure

- `AgentScope-Backend/` — Python FastAPI backend, SkillRegistry, SkillGuard sanitization engine, Windows AppContainer lab, MCP workbook server, and sample business Skills (`samples/business-skills/`).
- `AgentScope-Desktop/` — React + TypeScript + Tauri desktop application.
- `docs/archive/` — Archived technical verification and audit reports.
- `outputs/` — Exported evidence artifacts.
